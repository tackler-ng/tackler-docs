= First Round of Sales

Tackler supports storing single transactions into xref:journal:index.adoc#journal-files[single files], and it also has support for xref:journal:sharding.adoc[journal data sharding]. Both of these features are utilized, so that there won't be merge conflicts when these journals are merged.

This means that each transaction is stored its own file, and directory structure inside all journals (HQ, Store A and Store B) is constructed so that they won't be stepping on each other's toes.

Each transaction has an UUID and transactions are also tagged based on the store.
