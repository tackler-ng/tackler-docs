=== Tackler configuration

Store A's journal is just plain journal with optional xref:journal:git-storage.adoc[Git backend] support.

The journal setup is configured so that it's possible to switch between working copy journal (plain filesystem) and Git backend with `--input.storage "fs"` xref:reference:command-line.adoc#input-storage[command line argument].

Strict mode is activated, so that all accounts, commodities and tags must be defined. This prevents unknown accounting data to be used by Store A.

xref:auditing:index.adoc[Audit mode] is also activated, which means that tackler calculates checksums of used journal data.
