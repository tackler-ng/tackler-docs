== How to verify the Journal at HQ?

How do we know that this setup is working as intended, and that HQ really has all correct transactions from Stores? This is tricky question, especially when it's not feasible to audit (read) the full journal.

Let's collect all transaction UUIDs and then calculate manually what is the transaction set checksum.  In this example it's done fully manually, but there is a contrib script to calculate it in tackler's repository: {url-repo-tackler}/blob/main/contrib/txn-set-checksum.sh[txn-set-checksum.sh]
